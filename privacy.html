Privacy Policy

Kora Bel Masry (الكورة بالمصري) uses a private tool to upload its own videos to its own YouTube channel and Facebook Page.

What data the tool uses

The tool signs in only to the channel owner's own Google and Facebook accounts, with the owner's permission, and only to upload videos and their titles and descriptions. It does not access, collect or store data about any other person.

Storage and sharing

Access tokens are kept privately on the owner's computer. No data is sold, shared or used for advertising.

Google API Services

The tool's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. It uses the YouTube Data API only to upload videos to the owner's channel.

Removing access

The owner can revoke access at any time at myaccount.google.com/permissions or in Facebook settings.

Contact

Through the Kora Bel Masry Facebook Page.
